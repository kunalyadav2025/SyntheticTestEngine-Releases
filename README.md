# Synthetic Test Engine - Releases

Download the latest release of **Synthetic Test Engine** - a powerful image transformation tool for generating synthetic test data.

## Features

- 30+ image transforms (noise, blur, geometric, color, intensity, quality, edge detection)
- Batch processing with parameter ranges
- Seed-based reproducibility for repeatable tests
- Auto-preview with real-time updates
- Metadata JSON output for test traceability

## Installation

1. Download the latest release from the [Releases](https://github.com/kunalyadav2025/SyntheticTestEngine-Releases/releases) page
2. Extract the zip file to any folder
3. Run `SyntheticTestEngine.exe`

## System Requirements

- Windows 10/11 (64-bit)
- No installation required (portable)
